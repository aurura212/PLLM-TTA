# 实验记录（exp_record）

## 约定

- 文件名：`YYYY-MM-DD.md`（以实验主要推进的日期为准；跨日长跑可在启动日记一笔，收尾日记结果）
- 建议结构：
  1. **环境与配置**
  2. **当日操作**
  3. **结果**
  4. **问题与待办**
- 原始产物仍放在 `outputs/`；此处只写摘要与路径指针，不复制大缓存。
